# Achadinhos da Família - Robô de Afiliados Nuvem 🛍️

Serviço em nuvem (Render) para monitoramento de ofertas e cupons da Shopee, geração de Stories 9:16 com a marca oficial e automação de disparos para Telegram e WhatsApp.

## Rotas
- `/` - Dashboard de status
- `/ping` ou `/health` - Healthcheck para manter o serviço 24h ativo com UptimeRobot

## Tecnologias
- Python 3
- Flask & Gunicorn
- Telethon & Pillow
